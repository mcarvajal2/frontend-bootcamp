# User list backed by Firestore

User list backed by Firestore.

**Stack:** Vue 3, Vite, Vuex, Firebase Firestore.

## Run

From this folder:

```sh
npm install
npm run dev
```

Build with `npm run build`.

Copy `.env.example` to `.env` and provide the Firebase web app values before running. Client values are bundled into browser code; secure access with Firebase restrictions and service rules.
