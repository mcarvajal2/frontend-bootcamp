# Fullstack Bootcamp Projects

A curated collection of web development exercises, organized by learning module. Each project is self-contained and includes a short README with its stack and run instructions.

## Projects

| Folder | Description | Stack | Run |
|---|---|---|---|
| `01-html-css/git-landing` | GitHub landing page for a branching exercise | HTML, CSS | `python3 -m http.server 8000` |
| `01-html-css/viajes-chile` | Responsive Chile travel landing page with SCSS source | HTML, CSS, SCSS, Bootstrap | `python3 -m http.server 8000` |
| `02-javascript/notas-estudiante` | Student grades table exercise | HTML, JavaScript | `python3 -m http.server 8000` |
| `03-vue/01-cedula-identidad` | Chilean identity card mockup | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/02-tarjeta-credito` | Credit card mockup | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/03-editor-estilos` | Interactive style editor | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/04-gestor-citas` | Appointment manager | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/05-chat-aleatorio` | Random chat exercise | Vue 3, Vite, Axios | `npm install && npm run dev` |
| `03-vue/06-memoria-pokemon` | Pokémon memory game | Vue 3, Vite, Axios | `npm install && npm run dev` |
| `04-vue-router-vuex/01-ejercicios-vue` | Counter, routing and component communication exercises | Vue CLI, Vue Router, Vuex | `npm install && npm run serve` |
| `04-vue-router-vuex/02-tienda-alimentos` | Food catalog and shop | Vue CLI, Vue Router | `npm install && npm run serve` |
| `04-vue-router-vuex/03-tienda-juegos` | Game inventory with Vuex stock controls | Vue 3, Vite, Vuex | `npm install && npm run dev` |
| `05-firebase/01-usuarios-firestore` | User management with Firestore | Vue 3, Vite, Firebase | `npm install && npm run dev` |
| `05-firebase/02-auth-router` | Authentication screens with routed views | Vue 3, Vite, Firebase Auth | `npm install && npm run dev` |

## Running projects

Open a terminal in the project folder shown above. Serve static HTML exercises with the listed Python command. For Vue projects, install dependencies and run the listed development command. Firebase projects also require copying `.env.example` to `.env`; configure Firebase security rules separately.

# Proyectos Fullstack Bootcamp

Colección curada de ejercicios de desarrollo web, organizada por módulo de aprendizaje. Cada proyecto es independiente e incluye un README breve con su stack e instrucciones.

## Proyectos

| Carpeta | Descripción | Tecnologías | Ejecución |
|---|---|---|---|
| `01-html-css/git-landing` | Landing de GitHub para un ejercicio de ramas | HTML, CSS | `python3 -m http.server 8000` |
| `01-html-css/viajes-chile` | Sitio adaptable de viajes por Chile con fuentes SCSS | HTML, CSS, SCSS, Bootstrap | `python3 -m http.server 8000` |
| `02-javascript/notas-estudiante` | Ejercicio de tabla de notas de estudiante | HTML, JavaScript | `python3 -m http.server 8000` |
| `03-vue/01-cedula-identidad` | Maqueta de cédula de identidad chilena | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/02-tarjeta-credito` | Maqueta de tarjeta de crédito | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/03-editor-estilos` | Editor interactivo de estilos | Vue 3, Vite | `npm install && npm run dev` |
| `03-vue/04-gestor-citas` | Gestor de citas | Vue 3, Vite | `npm install && npm run dev` |

## Cómo ejecutar los proyectos

Abre una terminal en la carpeta del proyecto. Sirve los ejercicios HTML estáticos con el comando de Python indicado. Para los proyectos Vue, instala las dependencias y ejecuta el comando de desarrollo correspondiente. En los proyectos Firebase, copia `.env.example` a `.env` y configura las reglas de seguridad de Firebase por separado.
